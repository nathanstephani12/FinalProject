# Decentralized Arbitration Evaluation in Ethereum-Based Systems

## Project Goals
### 1. Compare decentralized arbitration protocols (Kleros, UMA, Colony) across design and governance models.
### 2. Analyze on-chain data to evaluate real-world arbitration outcomes and protocol effectiveness.
### 3. Explore technical architectures and smart contract mechanics of each arbitration system.
### 4. Conclude trade-offs and best use cases for each model.

## Tools and Technologies

- Python 3.12: Used for scripting to pull empirical data for models.
- Web3.py: Ethereum blockchain interaction library used for querying contracts, analyzing transactions, and accessing decentralized applications.
- Numpy and Pandas: Core data analysis libraries for manipulating blockchain datasets and processing arbitration results.
- Matplotlib and Scipy: Tools for visualization of data and linear regression analysis.

All development was done in on Ubuntu through WSL on an x86-based system

## Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/nathanstephani12/FinalProject.git
cd FinalProject
```

### 2. Create a Virtual Environment
```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```
